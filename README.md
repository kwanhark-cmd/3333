# 컴퓨터 하드 자료 검색 정리 비서

윈도우 PC에 연결된 큰 하드디스크들(예: 10TB × 5개)의 **사진·영상·문서를 한곳에서 찾아 주는 프로그램**입니다.
일기·메모·구글 일정·연락처까지 **한 검색창**에서 찾을 수 있어요.

- 하드디스크의 파일은 **절대 바꾸거나 옮기지 않아요.** 목록(색인)만 만들어요.
- 지우기는 내가 직접 누르는 **'휴지통으로 이동'** 하나뿐이고, 휴지통에서 언제든 되살릴 수 있어요.
- 모든 분석은 **내 PC 안에서만** 해요. 인터넷으로 보내지 않아요(AI 연결을 직접 켤 때만 예외).

---

## 내려받는 곳
모든 설치 파일은 **공개 Releases 페이지**에 있어요(GitHub 로그인 필요 없음):
**https://github.com/kwanhark-cmd/3333/releases/latest**

| 기기 | 받을 파일 |
|---|---|
| 윈도우 PC(본 프로그램) | `HDBiseo-Setup-x.y.z.exe` |
| 맥(보기 앱, 애플 실리콘 M1 이상) | `HDBiseo-x.y.z-mac.dmg` |
| 안드로이드 휴대폰(보기 앱) | `HDBiseo-x.y.z-android.apk` |

> 이 프로그램은 서명 열쇠 없이 만들어 배포해요. 그래서 처음 열 때 윈도우·맥이 한 번 확인을 묻고,
> **안드로이드 새 버전은 옛 앱 위에 바로 설치되지 않아요**(아래 3-1의 순서대로: 백업 → 받기 → 옛 앱 지우기 → 설치).

## 1. 윈도우 PC에 설치하기
1. 위 Releases 페이지에서 `HDBiseo-Setup-x.y.z.exe` 를 내려받아 두 번 누릅니다.
   - 'Windows의 PC 보호' 파란 창이 뜨면 **추가 정보 → 실행** 을 누르세요.
2. "다음"을 눌러 설치합니다. 원하면 **"컴퓨터를 켤 때 자동으로 시작(밤 색인용)"** 에 체크하세요.
3. 바탕화면의 **하드 자료 찾기 비서** 아이콘을 누르면 인터넷 창에 프로그램 화면이 열립니다.

## 1-1. 윈도우 새 버전 설치(업데이트) — 색인·설정은 그대로
- **설정 맨 위 → "업데이트 확인"** 을 누르면 새 버전이 있는지 알려주고, "지금 설치"를 누르면 설정·인물 정보를 백업한 뒤 내려받아 설치해요.
- 또는 Releases에서 새 `HDBiseo-Setup-x.y.z.exe` 를 받아 그냥 실행하면 새 버전으로 바뀌어요.
- 며칠 걸려 만든 **색인·썸네일·설정·얼굴 이름·메모·인맥**은 프로그램 폴더가 아니라 **사용자 자료 폴더**
  (`C:\Users\(내 이름)\AppData\Local\HDBiseo`, 설정 화면 '자료 위치'에 표시)에 있어서 새 버전을 설치해도,
  프로그램을 지웠다 다시 설치해도 남아요. 걱정되면 먼저 **설정 → 자료 관리 → 백업·복원 → 지금 백업**.
- 색인 형식이 바뀌는 버전이면 **자동으로 변환**하고(다시 분석하지 않음), 변환 전에 색인을 자동 백업해요.
- 분석(색인) 중에는 "분석이 끝난 뒤 해 주세요"라고 안내해요.

## 2. 처음 설정 (화면이 순서대로 안내해요)
1. **글씨 크기** 고르기 (보통 / 크게 / 아주 크게)
2. **하드디스크 고르기** — "하드디스크·폴더 추가"를 눌러 D:, E: 같은 하드를 고릅니다. 빼고 싶은 폴더는 "제외 폴더"로 지정.
   *먼저 체험해 보고 싶으면 "체험용 예제 폴더로 해보기"를 누르세요.*
3. **밤에만 색인할지** 고르기
4. **예상 시간**을 확인하고 "색인 시작하기"
   - 목록이 만들어지는 대로 바로 검색할 수 있어요.
   - 중간에 꺼져도, 하드를 뺐다 꽂아도 **이어서** 해요.

## 3. 맥·안드로이드에서 보기 (같은 와이파이 안에서만)
1. PC 화면에서 **설정 → 다른 기기에서 보기 → 켜기**, 그리고 프로그램을 한 번 껐다 켭니다.
2. 둘 중 편한 방법으로 엽니다.
   - **설치 없이**: 설정 화면에 나온 **주소**(예: `http://192.168.0.10:47810`)를 휴대폰·맥의 인터넷 창(크롬·사파리)에 입력. 크롬 메뉴의 **'홈 화면에 추가'** 로 아이콘도 만들 수 있어요.
   - **보기 앱**: Releases 페이지에서 맥은 `.dmg`, 안드로이드는 `.apk` 를 받아 설치. 맥 앱은 같은 와이파이의 PC를 스스로 찾고, 안드로이드 앱은 **'같은 와이파이에서 자동으로 찾기'** 를 누르면 찾아요(못 찾으면 'PC 주소 직접 입력').
     - 맥: dmg를 열어 앱을 **응용 프로그램** 폴더로 끌어 놓아요. 처음 열 때 막히면(macOS 15 이상)
       **시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기** 를 누른 뒤 다시 열어요.
     - 안드로이드: 받은 apk를 누르고 '출처를 알 수 없는 앱'을 물으면 허용해요. 휴대폰에 보이는 앱 이름은 **'하드 비서'** 예요.
3. 처음 한 번 **6자리 연결 번호**(PC 화면 설정 → 다른 기기에서 보기)를 입력하면 끝.
4. 연결이 안 되면 화면에 나오는 안내(같은 와이파이인지, PC가 켜져 있는지)를 확인하고 **"다시 찾기"** 를 누르세요.
- 아이폰은 아직 "준비 중"입니다(사파리로 주소 접속은 가능).

## 3-1. 보기 앱 새 버전으로 바꾸기
**안드로이드 — 꼭 이 순서대로** (새 앱은 옛 앱 위에 바로 설치되지 않아요)
1. **먼저 백업**: 앱에서 **설정 → 업데이트 확인 → ① 지금 백업** (또는 설정 → 자료 관리 → 백업·복원 → 지금 백업).
   백업 파일은 휴대폰 앱이 아니라 **PC에 저장**돼요. 옛 앱이 PC에 연결되지 않으면(1.1.0 앱 등) PC 화면에서 같은 곳을 눌러요.
2. **② 새 앱 파일 받기** 를 눌러(또는 Releases 페이지에서) 새 `.apk` 를 받아요.
3. 휴대폰에 깔린 옛 **'하드 비서'** 앱을 지워요. 휴대폰 앱에는 PC 주소와 연결 표만 있어서,
   지워도 PC의 색인·설정·얼굴 이름·메모는 그대로예요.
4. 받은 파일을 눌러 설치해요.
5. 새 앱을 열어 PC를 찾고, **6자리 연결 번호를 다시** 넣어요. 자료가 이상하면 설정 → 자료 관리 → 백업·복원에서 1번의 백업으로 복원해요.

**맥**: 새 dmg를 받아 앱을 응용 프로그램 폴더로 끌어 옛 앱과 바꿔요(자료는 모두 PC에 있어요).

## 4. 권장 PC 사양
| | 최소 | 권장(사진 수십만 장) |
|---|---|---|
| 운영체제 | 윈도우 10 (64비트) | 윈도우 11 |
| 메모리 | 8GB | **16GB 이상** |
| 그래픽카드 | 없어도 됨(얼굴·장면 인식이 느림) | 엔비디아 GeForce 계열 |
| 색인 저장 공간 | 파일 100만 개당 약 1GB + 썸네일(설정에서 한도) | SSD |

처음 색인은 하드 크기에 따라 몇 시간~며칠 걸릴 수 있어 **밤에 돌리기**를 권해요. 화면에서 예상 시간을 알려줘요.

## 5. 얼굴 인식·장면 찾기 켜기 (선택)
얼굴·장면 인식은 PC 안에서 돌아가는 공개 모델을 쓰며, **모델 파일을 넣으면 켜집니다.** 자세한 방법은 `docs/모델설치.md`.

## 6. 문제가 생기면
- **설정 → 문제 신고 파일 만들기** 를 눌러 만든 파일을 보내 주세요(파일 내용·연락처·일기는 들어가지 않아요).
- 색인이 이상하면 **설정 → 백업·복원·초기화** 에서 이전 백업으로 되돌리거나 초기화할 수 있어요(하드의 파일은 그대로).

## 개발자용
```
engine/      분석 엔진(Python, FastAPI, SQLite FTS5)
web/         보기 화면(HTML·CSS·JS, 빌드 없음). theme.css = 색·크기·움직임 한 파일
desktop/     Electron(윈도우·맥) + Capacitor(안드로이드) 포장
scripts/     100만 개 속도 측정 등
docs/보고    단계별 보고 / docs/검증 단계별 검증
```
- 엔진 실행: `cd engine && pip install -r requirements.txt && python -m hdbiseo`
- 엔진 테스트: `cd engine && pip install -r requirements-dev.txt && python -m pytest -q`
- 화면 테스트: `npm i playwright && node web/tests/ui-test.js`
- 체험용 샘플 폴더: `cd engine && python -m hdbiseo.samples 샘플폴더`
- 100만 개 속도: `python scripts/bench_million.py`
