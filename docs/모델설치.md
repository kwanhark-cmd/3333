# 얼굴 인식·장면 인식 모델 설치 (선택)

얼굴·장면 인식은 **PC 안에서만** 돌아가는 공개 모델을 씁니다. 사진이 인터넷으로 나가지 않아요.
모델이 없어도 프로그램의 다른 기능(검색·날짜별 보기·중복 정리·기록·목소리 구간)은 모두 동작합니다.

모델 폴더: 윈도우 기준 `C:\Users\(내 이름)\AppData\Local\HDBiseo\models`
(설정 화면 > 도움 아래 정보에서도 확인 가능)

## 1. 얼굴 인식 (InsightFace)
1. 파이썬 패키지 설치: `pip install insightface==0.7.3 onnxruntime==1.20.1`
   (엔비디아 그래픽카드가 있으면 `onnxruntime-gpu==1.20.1`)
2. InsightFace 공식 저장소의 `buffalo_l` 모델 묶음을 내려받아 아래처럼 풉니다.
   `models\insightface\models\buffalo_l\det_10g.onnx`, `w600k_r50.onnx` …
3. 프로그램을 다시 켜면 '사람' 화면의 "얼굴 인식이 꺼져 있어요" 안내가 사라지고 **얼굴 찾기 시작**을 누를 수 있어요.
- 주의: buffalo_l 모델은 **비상업적 연구용 라이선스**입니다. 판매용 제품에는 상업용 라이선스 모델로 바꿔야 해요(최종보고 '판매 단계 할 일' 참고).

## 2. 장면 인식 (OpenCLIP)
1. `pip install open_clip_torch==2.29.0 torch==2.5.1`
2. OpenCLIP `ViT-B-32`(laion2b) 가중치 파일을 `models\clip\open_clip_vit_b32.bin` 이름으로 넣습니다.
3. 다시 켜면 "비 오는 장면", "바닷가" 같은 말로 사진·영상 장면을 찾을 수 있어요.

## 동작 방식
- 색인의 추가 단계로 돌아갑니다(목록 → 사진 정보·문서 → 목소리 → 얼굴 → 장면). **하드 상태** 화면에서 잠시 멈춤·이어서 가능
- 영상은 장면을 10초마다, 얼굴은 30초마다 한 장씩 봅니다(ffmpeg 필요, 윈도우 설치 파일에 포함)
- 그래픽카드가 없으면 느리지만 CPU로도 동작합니다
